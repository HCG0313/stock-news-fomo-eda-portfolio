# 입력 데이터 출처와 범위

수업 과제에서 수집·전달한 두 Excel 파일을 최소한의 분석 열로 추출해 CSV로 저장했습니다. 값은 원본에서 가져왔으며, 추출 시 합성 관측치나 임의 보간값을 추가하지 않았습니다.

## 출처

| 파일 | 제공 자료 | 원본 입력 파일 | 단위·기간 |
|---|---|---|---|
| `stock_daily.csv` | KRX 주식 시세와 투자자별 매매 자료 | `주식통합.xlsx` | 종목·거래일별 2,410행, 10종목×241거래일 |
| `attention_daily.csv` | 네이버 데이터랩 검색 지수와 빅카인즈 기사 건수 | `뉴스, 검색 데이터.xlsx` | 종목·달력일별 3,620행, 10종목×362일 |

기간은 2024-12-02~2025-11-28입니다. 원본 주식 파일에 삼성전자·에코프로의 2024년 11월 자료 4행이 추가로 있어, 뉴스·검색 자료와 겹치는 기간으로 제한했습니다.

출처 명칭은 팀 발표자료와 제공된 파일의 구성에 근거합니다. 구체적인 API 요청 코드, 키워드 조합·검색 필터의 전체 기록은 확인되지 않아 추정해 적지 않았습니다. CSV 이후의 분석을 재현할 수 있으며, 외부 서비스에서 동일한 자료를 새로 수집하는 전체 과정까지 재현한다고 주장하지 않습니다.

## 열 설명

`stock_daily.csv`

- `stock`, `date`: 종목명과 거래일
- `close`: 종가(원)
- `return_pct`: 원본에 기록된 전 거래일 대비 등락률(%)
- `volume`: 거래량(주)
- `retail_buy`, `retail_sell`, `retail_net_buy`: 개인 매수·매도·순매수 수량(주)

`attention_daily.csv`

- `stock`, `date`: 종목명과 뉴스·검색 발생일
- `search_index`: 제공된 네이버 데이터랩 검색 지수. 실제 검색 횟수와 구분
- `news_count`: 수집 조건에 해당하는 기사 건수. 원문·감성·기사별 공개 시각은 포함하지 않음

자료를 재사용할 때는 원 제공처의 이용 조건과 수집 범위를 확인해야 합니다. 이 저장소는 제3자 원자료에 대한 별도 이용 허락을 부여하지 않습니다.

## 추출 기록과 재현

원본 및 CSV의 SHA-256은 `provenance.json`에 기록했습니다. 원본 Excel을 가지고 있다면 다음 명령으로 동일한 CSV를 다시 만들 수 있습니다.

```bash
python -m pip install openpyxl==3.1.5
python scripts/prepare_data.py "원본 Excel 두 개가 들어 있는 폴더" --destination data
```

추출 스크립트는 정확한 열 이름을 지정합니다. 분석 코드에서는 중복 키, 원본 결측치, 매수−매도와 순매수 일치, 종목별 거래일 누락, 달력일별 관심 데이터 누락을 검사합니다.

거래일 목록은 수집된 주식 데이터의 날짜에서 추출합니다. 모든 종목에서 같은 날짜가 함께 누락된 경우까지 확인한 공식 거래소 달력 검증은 아닙니다.
